We are looking for a Full Stack Developer who is comfortable moving between building Web3 applications and building websites that are clean and pleasant to use. You will work directly with the founder and the product team, from idea to release.

## What you'll be doing
- Build and maintain web applications using Next.js and TypeScript
- Design and implement REST APIs with standard JSON payloads and efficient MongoDB data structures, and own the services you build until they run reliably in production
- Integrate the frontend with smart contracts and on-chain services, including wallet connection, reading contract state, and sending transactions
- Build responsive, fast websites and landing pages that match the design
- Write supporting services or scripts, typically in Node.js or Python, as needed
- Review code, keep the codebase healthy, and help shape the technical direction of our products
- Handle deployment, monitoring, and production issues

## What we're looking for
- Strong command of JavaScript and TypeScript
- Solid experience with React and Next.js, including the App Router
- Experience building backends and taking full ownership of them. The language and framework are up to you, whether Node.js, Python, Go, PHP, or something else. What we care about is your ability to design APIs, handle authentication and input validation, and keep a service running in production
- Strong working knowledge of MongoDB, including document structure design, indexing, and aggregation pipelines, and comfort working with standard JSON
- Comfortable with Git and collaborative workflows such as branching, pull requests, and code review
- Able to turn Figma designs into clean, responsive interfaces
- Comfortable using AI coding tools such as Cursor, GitHub Copilot, or Claude to work faster, with a clear sense of when their output needs correcting
- Able to work independently, break large problems into small steps, and communicate clearly about progress and blockers
- Understanding of Web3 fundamentals, including how wallets work, how on-chain transactions behave, and how a frontend interacts with smart contracts
- Experience with Web3 libraries such as ethers.js, viem, or wagmi for wallet connection, reading contract state, and sending transactions
- Able to read an ABI and call smart contract functions from an application
- Understanding of the transaction lifecycle, including gas, nonce, and pending states, and how to handle them in the user interface

## Other Requirements
- Basic English communication skills, which will be assessed during subsequent interviews
- No minimum years of experience required. We assess real ability and the work you have built, so please share a portfolio, GitHub, or projects we can look at
