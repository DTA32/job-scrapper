## Job Description
The Front End Engineer is responsible for developing and implementing interactive, responsive, and high-performing user interfaces for web and/or mobile applications.

The role ensures a consistent and seamless user experience while delivering front-end solutions that align with business requirements, technical standards, and approved UI/UX designs.

## Key Responsibilities
- Develop and implement user interfaces based on approved UI/UX designs.
- Translate designs from Figma, Adobe XD, Balsamiq, or similar design tools into high-quality, functional front-end code.
- Ensure applications are responsive, accessible, and compatible across different devices, browsers, and screen sizes.
- Collaborate closely with UI/UX Designers, Back End Engineers, Business Analysts, QA Engineers, and other project stakeholders.
- Write clean, structured, efficient, and maintainable code in accordance with development best practices.
- Integrate and consume REST APIs and/or GraphQL services with back-end systems.
- Troubleshoot and resolve front-end issues to ensure optimal application performance and usability.
- Support software testing, UAT, and deployment activities when required.
- Follow established development standards, coding guidelines, and project best practices.
- Contribute to continuous improvement of front-end development processes, architecture, performance, and overall user experience

Qualifications

- Bachelor’s degree in Computer Science, Information Systems, Informatics Engineering, or a related field, or equivalent experience.
- Minimum 3 years of professional experience as a Front End Engineer / Developer.
- Strong understanding of HTML, CSS, and JavaScript.
- Hands-on experience with modern front-end frameworks and libraries.
- Good understanding of responsive design, cross-browser compatibility, Client-Side Rendering (CSR), Server-Side Rendering (SSR), and Progressive Web Applications (PWA).
- Ability to work independently as well as collaboratively within a project team.
- Previous experience working in a financial services company is a strong advantage.

## Technical Skills
- Core Technologies: HTML, CSS, JavaScript, TypeScript, and Node.js.
- Frameworks / Libraries: React.js and/or Next.js; experience with Tailwind CSS is an advantage.
- Experience working with REST APIs and/or GraphQL.
- Proficiency with Git / version control systems.
- Familiarity with modern build tools such as Vite, npm, and pnpm.
- Familiarity with Kafka, Valkey, Spring Cloud Gateway, and Firebase Cloud Messaging (FCM) is an advantage.

## Soft Skills
- Strong problem-solving and analytical skills.
- High level of attention to detail.
- Excellent communication and collaboration skills.
- Good time management and organizational skills.
- Willingness to continuously learn and adopt new technologies and development practices.
- Strong appreciation for user experience (UX), usability, and visual aesthetics.
