## Job Description
We are looking for a hands-on QA Automation Engineer to improve the quality, reliability and release confidence of our web, mobile and backend applications.

This role is primarily focused on automated testing. You will design, develop and maintain reusable automation frameworks and test scripts covering UI, API, integration and regression testing. You will also perform manual and exploratory testing where automation is not practical.

The ideal candidate has practical experience writing automation scripts, integrating automated tests into CI/CD pipelines, analysing failures and working closely with development teams to prevent defects throughout the software development lifecycle.

## Key Responsibilities
- Test Automation Development

- Design, develop and maintain automated test frameworks for web, mobile and API applications.
- Create reusable, maintainable and reliable automated test scripts.
- Automate functional, regression, smoke, integration and end-to-end test scenarios.
- Review existing manual test cases and identify suitable candidates for automation.
- Maintain test data, test environments and reusable automation components.
- Investigate failed automated tests and distinguish application defects from script or environment issues.

- Web and Mobile Application Testing

- Automate web application testing using tools such as Selenium, Cypress or Playwright.
- Automate mobile application testing using Maestro, Appium, Espresso, XCUITest or equivalent frameworks.
- Develop and maintain Maestro test flows for critical user journeys, smoke testing, regression testing and end-to-end testing across iOS and Android applications.
- Validate application behaviour across supported browsers, devices, screen sizes and operating systems.
- Perform manual and exploratory testing for complex scenarios that cannot be effectively automated.

- API and Backend Testing

- Develop automated API tests using tools or frameworks such as Postman/Newman, REST Assured or equivalent.
- Validate API requests, responses, authentication, business rules and error handling.
- Perform database queries to verify data integrity and backend processing.
- Test integrations between mobile applications, web applications, APIs and external systems.

- CI/CD and Continuous Testing

- Integrate automated test suites into CI/CD pipelines.
- Work with developers and DevOps engineers to execute automated tests during builds, deployments and scheduled regression runs.
- Monitor automation results and provide clear reporting on test coverage, failures and release risks.
- Improve execution speed, stability and reliability of automated test suites.

- Test Planning and Quality Assurance

- Review business requirements, user stories and technical specifications to identify test scenarios.
- Prepare and maintain test plans, test cases, test scripts and traceability records.
- Conduct functional, regression, integration, usability and compatibility testing.
- Support SIT, UAT, release validation and post-deployment verification.
- Contribute to performance testing using tools such as JMeter, k6, Gatling or LoadRunner, where required.

- Defect Management and Collaboration

- Identify, document and track defects with clear reproduction steps, evidence, severity and business impact.
- Work closely with developers, business analysts, project managers and DevOps engineers to resolve issues.
- Participate in Agile activities, including sprint planning, backlog refinement, daily stand-ups and retrospectives.
- Promote early testing and quality ownership throughout the development lifecycle.
- Recommend improvements to test processes, automation coverage and release quality.
